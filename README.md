# CellVeilXL

VBA-инструмент для шифрования и стеганографического сокрытия данных в форматировании Excel-документа.

## Быстрый старт

```vba
' 1. Заполните листы:
'    List1!A1 = текст для сокрытия
'    List1!B1 = пароль
'    List2    = документ-носитель (обычный текст)

' 2. Спрятать:
Call EmbedScr
' → "Done. Embedded 328 of 474 bits."

' 3. Сохранить как .xlsx (макросы вырезаются, форматирование остаётся)

' 4. Извлечь:
Call ExtractScr
' → List1!C1 = исходный текст
```
## Как работает

текст + пароль
   → RC4-шифрование
   → пакет: [длина 4б][шифртекст Nб][XOR-чексумма 4б]
   → биты (MSB-first)
   → форматирование List2:
        2 бита / ячейку  → Orientation (0°–3°)
        4 бита / символ  → Font.Color (RGB 0..15)

## Основные процедуры

EmbedScr      ' List1!A1 + List1!B1  →  скрыть в List2
ExtractScr    ' List2               →  List1!C1 (по паролю из List1!B1)

## Емкость

2 × N_ячеек  +  4 × N_символов   бит
